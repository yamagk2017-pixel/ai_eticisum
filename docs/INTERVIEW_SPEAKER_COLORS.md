# インタビューの話者名の文字色

Sanity StudioのNews Articleにある「話者名の文字色（インタビュー）」で、話者ごとに色を設定します。

1. 「話者の色」を追加します。
2. 本文と同じ話者名を入力します。例：`ミッポ`。コロンは不要です。
3. 色見本またはカラーピッカーで選びます。メンバーカラーなどの指定がある場合は、`#f97316`のような色コードも直接入力できます。
4. 記事プレビューで確認します。

この設定は、記事の全ページで段落先頭の「ミッポ：」「ミッポ:」に適用されます。本文中で名前に言及する箇所や回答本文の色は変えません。複数人のインタビューでは話者ごとに追加してください。色を変えると、その話者名の表示が一括で変わります。設定を削除すると通常の文字色に戻ります。

原稿取り込み時にも、`draft.md`のメタデータに次のように指定できます。Sanityの下書き作成後はStudioから変更できます。

```yaml
speakerColors:
  - speakerName: "ミッポ"
    color: "#f97316"
  - speakerName: "別の話者"
    color: "#3b82f6"
```

話者名は本文と完全一致で判定します。`ミッポ`と`ヒノメ ミッポ`は別の設定です。同じ話者名を重複登録することはできません。色コードは`#`に続く6桁の16進数を指定してください。

従来の本文ツールバーの「オレンジ」書式も利用できますが、繰り返し登場する話者名には記事単位の設定を使ってください。
